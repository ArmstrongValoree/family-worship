# New UI Component
Create a new reusable component in src/components/ui/.

Steps:
1. Create the file at src/components/ui/[ComponentName].tsx
2. Define a TypeScript props interface
3. Use only Tailwind paradise-* classes for colors
4. Export as named export
5. Add JSDoc comment describing what the component does
6. Commit: feat(ui): add [ComponentName] component
