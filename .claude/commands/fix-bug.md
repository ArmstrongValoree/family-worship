# Fix Bug
Debug and fix an issue in the codebase.

Steps:
1. Read the file(s) involved before making any changes
2. Identify the root cause — do not guess
3. Explain the cause clearly before fixing
4. Make the minimal change needed to fix the issue
5. Verify no TypeScript errors: npx tsc --noEmit
6. Commit: fix(scope): description of what was fixed
