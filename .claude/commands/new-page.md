# New Page
Create a new page component in src/pages/.

Steps:
1. Create the file at src/pages/[category]/[PageName]Page.tsx
2. Use the ParadiseBackground (already fixed full-screen — do not re-add it)
3. Wrap content in a frosted glass card: 
   className="backdrop-blur-md bg-white/10 border border-paradise-green-light/20 rounded-2xl p-6"
4. Add the route to App.tsx
5. Add a navigation link if applicable in BottomNav.tsx
6. Use font-display for headings, font-body for body text
7. Commit: feat(pages): add [PageName] page
